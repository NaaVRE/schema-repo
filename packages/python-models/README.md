# python-models

Auto-generated [Pydantic v2](https://docs.pydantic.dev/latest/) models produced from the canonical JSON schemas in `schemas/`.

> **Do not edit files under `src/models/` manually.** They are regenerated by running:
>
> ```bash
> ./generators/generate_python.sh
> ```

## Installation

```bash
pip install naavre-python-models
```

Or, from the repo root in development mode:

```bash
pip install -e packages/python-models[dev]
```

## Usage

```python
from models import User, UserCreate, Order, OrderStatus

user = User(
    id="123e4567-e89b-12d3-a456-426614174000",
    username="alice",
    email="alice@example.com",
    is_active=True,
    created_at="2024-01-01T00:00:00Z",
    updated_at="2024-01-01T00:00:00Z",
)
print(user.model_dump())
```

## Regenerating models

```bash
pip install datamodel-code-generator
./generators/generate_python.sh
```
