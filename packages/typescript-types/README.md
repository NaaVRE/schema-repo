# typescript-types

Auto-generated TypeScript types produced from the canonical JSON schemas in `schemas/`.

> **Do not edit files under `src/` manually.** They are regenerated by running:
>
> ```bash
> ./generators/generate_typescript.sh
> ```

## Installation

```bash
npm install @naavre/typescript-types
```

Or, from the repo root in development mode:

```bash
cd packages/typescript-types && npm install
```

## Usage

```typescript
import type { User, UserCreate, Order, OrderStatus } from "@naavre/typescript-types";

const user: User = {
  id: "123e4567-e89b-12d3-a456-426614174000",
  username: "alice",
  email: "alice@example.com",
  is_active: true,
  created_at: "2024-01-01T00:00:00Z",
  updated_at: "2024-01-01T00:00:00Z",
};
```

## Regenerating types

```bash
npm install -g json-schema-to-typescript
./generators/generate_typescript.sh
```
